Php-"Hypertext pre procesor"
    open source skriptovací jazyk bežiaci na strane servera
        MAMP-loc. server beží na pc, poskituje služby: Apache,PHP,databayzovi server
Architektúra klient-server: kód sa vykoná na serveri, klientovi posle vygenerovany HTML a CSS kod
-Tvorba dyn. web. aplikácií, API rozhraní, komunikuje s dataázou a spracovanie formulárov
        (<?php?>)
Výstup
    echo/print-na písanie
premenné-
    zaciatok dolárom, písmenom/podčiarkovníkom
Dátové typy-
    string(text), int, float, Boolean(bool)
        znak . -spájanie textu s premennou
Text v PHP vieme:
                -spájať
                -upravovať podľa stoviek funkcií
Čísla a Matematika- generovanie random čísel(rand())                !!!!!(= )
                    zaokruhlovanie(round())
                    min/max
Pretypovanie
    strlen-dlzka textu
    str_replace-nahradiť text
Konštanty(constants)-
    hodnoty, ktoré sa počas behu skriptu nedajú zmeniť (prístupové heslá, fixné nastavenia)
Operátry:-matematické/aritmetické (modulo,porovnávanie, logické)
